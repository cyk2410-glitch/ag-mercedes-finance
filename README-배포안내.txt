AG 천팀장 벤츠할부 홈페이지

1. ZIP을 풀어 GitHub 저장소 루트에 파일/폴더를 그대로 업로드합니다.
2. Cloudflare Pages: GitHub 연결, Framework preset None, Build command 비움, Build output directory / 또는 . (저장소 루트).
3. 실제 배포 도메인 확정 후 robots.txt와 sitemap.xml의 YOUR-MERCEDES-DOMAIN을 실제 호스트로 교체하고 재배포하세요.
4. Cloudflare Pages Functions 파일 functions/api/latest-posts.js가 배포되어야 블로그 최신 6건 자동 표시를 시도합니다. 네이버 RSS 접근 정책에 따라 일부 또는 전부 수집 실패할 수 있습니다.
5. 대표 이미지/파비콘은 업로드한 AG 원본 사진에서 복사했으며 외부 벤츠 사진은 임의 사용하지 않았습니다. 모델 카드에는 텍스트를 사용합니다.
6. SEO 제목/설명글, OG, JSON-LD, 모바일 레이아웃, 4개 사례, 모델 필터, FAQ를 포함합니다.
7. 공식 금융사 사이트가 아니며 상품별 최종 조건은 심사/약정에 따릅니다.
8. 배포 후 실제 페이지와 모바일, 카드 필터, 블로그 API, 파비콘/OG, 사이트맵을 확인하세요.
